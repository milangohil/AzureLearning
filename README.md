# AzureLearning
Dashboard to learn Azure Services

## Step 1 dashboard: Azure Learning Tracker

`index.html` is a single-page study dashboard for the AZ-900 (Azure Fundamentals) and AI-901 (Azure AI Fundamentals) foundations. It has no build step and needs no install.

**What's inside**
- **6 study areas, 68 topics:** Fundamentals, Compute, Networking, Storage, Security & identity, and AI services. The AI area goes deep on Microsoft Foundry: models and model router, APIs and SDKs, Agent Service, hosted agents, tools and Toolbox, memory and Routines, Foundry IQ, Control Plane, guardrails and cost control. It also covers every Foundry Tool, Azure Machine Learning and the renamed or retired services.
- **15 hands-on labs:** copy-ready Azure CLI commands, cost notes and clean-up steps.
- **Progress tracking:** tick topics as you learn them to see overall %, hours left and what to study next.
- **Status tags and a change log:** AI topics are tagged GA, preview or retiring as of 29 Oct 2026, with a re-check note and a dated 2026 change log, because Foundry changes every month.
- **Exam map:** how the areas line up with the AZ-900 and AI-901 skill weights.

**How to open it**
- Locally: download `index.html` and double-click it.
- Online: go to Settings > Pages, set the source to the `main` branch and `/ (root)`, and open `https://milangohil.github.io/AzureLearning/`.

Progress is saved in your browser only, so it won't follow you to another device.
