# AzureLearning
Dashboard to learn Azure Services

## Step 1 dashboard: Azure Learning Tracker

`index.html` is a single-page study dashboard for the AZ-900 (Azure Fundamentals) foundations. It has no build step and needs no install.

**What's inside**
- **5 study areas, 32 topics:** Fundamentals, Compute, Networking, Storage, Security & identity. Each topic has a plain explanation, a real-life example, key exam facts and a Microsoft Learn link.
- **7 hands-on labs:** copy-ready Azure CLI commands, cost notes and clean-up steps.
- **Progress tracking:** tick topics as you learn them to see overall %, hours left and what to study next.
- **AZ-900 exam map:** how the areas line up with the exam's skill weights.

**How to open it**
- Locally: download `index.html` and double-click it.
- Online: go to Settings > Pages, set the source to the `main` branch and `/ (root)`, and open `https://milangohil.github.io/AzureLearning/`.

Progress is saved in your browser only, so it won't follow you to another device.
